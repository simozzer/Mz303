The first release of **Mz303**, an emulation of the Roland TB-303 Bass Line, as a VST3 instrument and a standalone app for Windows.

![The Mz303 panel](https://raw.githubusercontent.com/simozzer/Mz303/v0.1.0/docs/screenshot.png)

Mz303 models the 303's circuit:
- **Filter:** the diode ladder, four RC sections that load each other. It has a broad, vocal resonance that squelches without quite whistling, and highpassed feedback that spares the lowest notes.
- **Oscillator:** a saw core, with the square made from it by a waveshaper, as on the original. Each half of the square still leans like the saw.
- **Envelopes:** a decay-only filter envelope, and an amp envelope with no knob that fades while a note is held.
- **Accent:** louder, brighter and always short. At high resonance accents swell, and a run of them climbs: the 303's "wow".
- **Slide:** a fixed glide that restarts neither envelope.

**The full panel:** TUNING, CUT OFF FREQ, RESONANCE, ENV MOD, DECAY, ACCENT, WAVEFORM and VOLUME.

**Played from MIDI:** velocity 100 or more is an accent, and a note played before the last one is let go slides.

**Added for DAW use:**
- **MIDI control:** every control has a MIDI CC, and you can MIDI-learn your own.
- **Hover hints** on every control.
- **Eight factory patches.**

### Download

| File | What it is |
|---|---|
| `Mz303-0.1.0-win64-Setup.exe` | **The installer.** Run it, then rescan plugins in your DAW. |
| `Mz303-0.1.0-win64-VST3.zip` | The plugin, to install by hand. Copy `Mz303.vst3` to `%LOCALAPPDATA%\Programs\Common\VST3` (or `C:\Program Files\Common Files\VST3`) and rescan in your DAW. |
| `Mz303-0.1.0-win64-Standalone.zip` | `Mz303.exe`, which plays without a DAW. |

Windows 10 or 11, 64-bit. The installer and binaries aren't code-signed, so Windows may warn about an unknown publisher. Choose *More info → Run anyway*, or build from source.

### Known limitations
- **No pattern sequencer yet.** Accent and slide come from velocity and overlapping notes.
- **Windows only** for now.
- **Not calibrated against a real TB-303.** The circuit's structure is modelled, but its ranges, times and levels are reasoned, not measured from a unit.
